# Instructor Effectiveness Modeling

Data Science / AI Content Specialist Internship Assignment

This project analyzes instructor effectiveness in an EdTech context by:
- Aggregating batch-level data to instructor level
- Creating a weighted effectiveness score
- Classifying instructors into Low, Medium, and High tiers
- Training a Random Forest classifier
- Evaluating model performance
- Interpreting feature importance
- Discussing business, ethical, and real-world limitations
